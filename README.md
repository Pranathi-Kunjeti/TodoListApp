# iTask - Todo Manager

A responsive Todo Management application built using React and Tailwind CSS. The application allows users to create, edit, delete, and manage tasks efficiently with data persistence through Local Storage.

## Features

* Add new todos
* Edit existing todos
* Delete todos
* Mark todos as completed or incomplete
* Show or hide completed todos
* Persistent storage using Local Storage
* Responsive user interface
* Unique task identification using UUID

## Tech Stack

* React.js
* JavaScript (ES6+)
* Tailwind CSS
* UUID
* Local Storage API
